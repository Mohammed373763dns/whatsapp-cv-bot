# بوت الفحص المجاني

البوت بيعمل شغلة وحدة بس:
1. الزبون بيكتب "بدي افحص سيرتي" / "فحص مجاني" ← البوت: ابعتلنا سيرتك للفحص
2. الزبون بيبعت الملف ← البوت: تمام، الفريق رح يفحصها ويزودك بالنتائج
3. البوت بيفحص السيرة، والنتيجة بتطلعلك بالداشبورد ← بتراجعها وبتكبس "ابعت للزبون" (وإذا ما بعتها بتنبعت لحالها بعد ربع ساعة)

- الفحص مرة وحدة لكل رقم (من الداشبورد بتقدر تسمح لرقم بفحص تاني).
- الملف بينفحص بس إذا الزبون طلب فحص قبله (أو كتب الطلب مع الملف).
- أي رسالة تانية البوت ما بيرد عليها.

## التشغيل

| الأمر | شو بيعمل |
|---|---|
| `npm run bot` | بيشغّل البوت والداشبورد على http://localhost:3000 |
| `npm test` | الاختبارات |

أول مرة: `npm install`، انسخ `.env.example` لـ `.env` وحط مفتاح Grok، وبعدين `npm run bot` وامسح الـQR من الداشبورد.

> بعد أي تحديث للكود: وقّف البوت (Ctrl+C) وشغّله من جديد.

## الرفع على Railway
1. ارفع المشروع على GitHub (repo **خاص**). ملفات `.env` والجلسة و`data/` مستثناة لحالها.
2. railway.app ← **New Project ← Deploy from GitHub repo** ← اختار الـrepo. بيلقى الـ`Dockerfile` و`railway.json` لحاله.
3. على الخدمة: **Settings ← Volumes ← Add Volume** على المسار **`/app/storage`** (هون بتنحفظ جلسة الواتس وقاعدة البيانات).
4. **Variables**: `XAI_API_KEY`، `XAI_MODEL_FAST`، `OPTI_BOT_KEY`، `DAILY_AI_BUDGET_USD`، و **`DASHBOARD_PASSWORD`** (بدونها الداشبورد ما بتفتح).
5. **Settings ← Networking ← Generate Domain** ← افتح الرابط، اكتب كلمة السر (اسم المستخدم أي إشي)، وامسح الـQR.
6. وقّف البوت على اللابتوب — ما بيشتغلوا الاتنين على نفس الرقم.

ملاحظات: خليه نسخة وحدة (Replicas = 1). البوت بياكل تقريباً 0.5–1GB رام بسبب المتصفح. على السيرفر الورد بيتحول PDF بـ LibreOffice بدل Word، فالدرجة ممكن تختلف شوي بالسير المعقدة.

## الداشبورد
- **زر تشغيل/إيقاف** البوت.
- **نتائج بانتظارك:** نتيجة كل فحص مع صورة الدرجة. بتقدر تعدّلها قبل ما تبعتها. إذا الفحص فشل بتكتب النتيجة بإيدك.
- **آخر الطلبات:** مين طلب فحص ووين وصل.
- **رسائل البوت والإعدادات:** نص الرسالتين، بعد كم دقيقة النتيجة بتنبعت لحالها (افتراضي 15)، وتغيير رقم الواتس.

## وين كل شي بالكود
- `src/flow.js` — منطق البوت كله
- `src/cv/` — فحص السيرة
- `src/whatsapp/` — الاتصال والإرسال الآمن
- `src/dashboard/` — الداشبورد
- `backup-before-simplify/` — النسخة القديمة بكل السيناريوهات (بتقدر تحذفها إذا ما بدك اياها)
