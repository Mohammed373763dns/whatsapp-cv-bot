# بوت الفحص المجاني

البوت بيعمل شغلة وحدة بس: **فحص الملف اللي بينبعتله**.

- أي شخص يبعت ملف للبوت، البوت بسأله: «شو رقم صاحب الملف؟» وبعدها بيقلّه «جاري الفحص».
- لما يخلص الفحص، النتيجة بتنبعت **للمستخدم فوراً** بدون انتظار، ومعها زر «أرسل الفحص لهذا الرقم».
- الزر بيظهر عند المستخدم مو عندك. إذا كبس الزر، البوت بيبعت نفس الفحص لرقم صاحب الملف. إنت ما بتبعث شي.
- الكلام العادي ما بيرد عليه. كل رقم بقدر يفحص قد ما بدّه.
- تغيير رقم الواتس بيمسح محادثات الرقم القديم من اللوحة.

## التشغيل

| الأمر | شو بيعمل |
|---|---|
| `npm run bot` | بيشغّل البوت والداشبورد على http://localhost:3000 |
| `npm test` | الاختبارات |

أول مرة: `npm install`، انسخ `.env.example` لـ `.env` وحط مفتاح Grok، وبعدين `npm run bot` وامسح الـQR من الداشبورد.

> بعد أي تحديث للكود: وقّف البوت (Ctrl+C) وشغّله من جديد.

## الرفع على Railway
1. ارفع المشروع على GitHub (repo **خاص**). ملفات `.env` والجلسة و`data/` مستثناة لحالها.
2. railway.app ← **New Project ← Deploy from GitHub repo** ← اختار الـrepo. بيلقى الـ`Dockerfile` و`railway.json` لحاله.
3. على الخدمة: **Settings ← Volumes ← Add Volume** على المسار **`/app/storage`** (هون بتنحفظ جلسة الواتس وقاعدة البيانات).
4. **Variables**: `XAI_API_KEY`، `XAI_MODEL_FAST`، `OPTI_BOT_KEY`، `DAILY_AI_BUDGET_USD`، و **`DASHBOARD_PASSWORD`** (بدونها الداشبورد ما بتفتح).
5. **Settings ← Networking ← Generate Domain** ← افتح الرابط، اكتب كلمة السر (اسم المستخدم أي إشي)، وامسح الـQR.
6. وقّف البوت على اللابتوب — ما بيشتغلوا الاتنين على نفس الرقم.

ملاحظات: خليه نسخة وحدة (Replicas = 1). البوت بياكل تقريباً 0.5–1GB رام بسبب المتصفح. على السيرفر الورد بيتحول PDF بـ LibreOffice بدل Word، فالدرجة ممكن تختلف شوي بالسير المعقدة.

## لوحة التحكم
- **زر تشغيل/إيقاف** البوت لكل الأرقام.
- **نتائج بانتظارك:** فحص فشل أو فحص إيدك من اللوحة. الفحص التلقائي بينبعت للمستخدم لحاله، إنت ما بتبعثه.
- **المحادثات:** كل الأرقام ومحادثاتها. لكل رقم:
  - **سكّت البوت مع هالرقم** — البوت ما بيفحصله ولا بيرد عليه
  - **امسح سجل البوت** — الرقم بيرجع جديد وبيقدر ينفحص مرة كمان (المحادثة بتضل)
  - **احذف من اللوحة** — بتنحذف من اللوحة بس، مش من الواتس
  - **افحص هاد الملف** — جنب أي ملف من الزبون، فحص بإيدك
  - خانة تبعت منها رسالة للزبون
- **الإعدادات:** نص الرد الآلي، بعد كم دقيقة النتيجة بتنبعت لحالها، وتغيير رقم الواتس.
